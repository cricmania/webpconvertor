# WebP Converter

A premium, high-performance web application to convert images to WebP, JPEG, and AVIF formats with batch processing support.

## Features
- **Batch Processing**: Convert multiple images at once.
- **Format Support**: Convert to WebP, JPEG, and AVIF.
- **Quality Control**: Adjust compression quality for the perfect balance between size and clarity.
- **Batch Renaming**: Automatically rename files using patterns.
- **Privacy First**: All processing happens locally in your browser. No images are uploaded to any server.
- **Modern UI**: Sleek, responsive design with dark mode and smooth animations.

## Tech Stack
- **Framework**: Next.js 15
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Compression**: Browser Canvas API
- **Zip Support**: JSZip

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deployment

The easiest way to deploy this app is to use the [Vercel Platform](https://vercel.com/new).
